# 页面进退与弹窗开关

## 当前范围

- 页面导航覆盖四个 Tab 进入业务页，以及业务页之间的多层进退，包括待办、目标、财务、阅读观影、设备、衣柜、会员、管理和“我”的设置链。四个底部 Tab 之间保留平级切换，不播放层级推入。
- H5 在路由确认阶段捕获页面，前进时新页面从右侧进入、旧页面向左轻退；返回时旧页面向右退出、上一页回到原位。往返使用同一组几何位置，时长 360ms。
- 登录/账号验证、同页参数变化、`redirectTo` / `reLaunch` 重置导航和 `switchTab` 不播放层级动效。浏览器后退/前进按历史位置判定方向；普通导航在菜单锁放行后记录实际操作，返回 Tab 时仍保留反向退场。
- App 对上述 `navigateTo` / `navigateBack` 使用原生窗口过渡；显式指定的动画参数优先。微信不叠加自绘的整页导航动画。
- 主题切换仍使用独立的 800ms 圆形往返，不与普通页面推入混用。

## 公共弹窗

H5 的 `ModalMotion` 放在业务条件外，保留关闭后的短暂退场过程。遮罩与面板同步进入，面板只做轻微位移和缩放；进入 300ms，退出 240ms。动画完成后不保留 transform，避免改变固定定位、日期选择器与滚动容器的参照。

```vue
<ModalMotion>
  <AdaptiveModal v-if="editing" ref="editorModal" label="编辑记录" :busy="saving" @close="editing = false">
    <!-- 表单内容 -->
    <MobileButton label="取消" variant="quiet" :disabled="saving" @click="editorModal?.close()" />
  </AdaptiveModal>
</ModalMotion>
```

`editorModal` 使用 `ref<{ close: () => void } | null>(null)`。如果弹窗封装在单独的编辑器组件中，父层按条件挂载该编辑器的边界也需要 `ModalMotion`。

取消和遮罩应调用同一个公共 `close()` 入口，再由 `@close` 执行业务清理。微信/App 的公共关闭入口先完成退场，再通知父层卸载；进入关闭阶段后阻止面板继续操作。写入中不接受关闭，离页卸载会取消未完成的关闭回调。账户变化、离页清理等强制销毁不应等待动画。

业务直接修改 `v-if` 状态时，H5 由父层过渡边界处理退场；微信/App 需要显式使用 `close()` 才有退场，不应为延迟销毁而推迟业务数据失效。保存成功后若希望播放退场，应在写入完成后通过公共关闭入口结束弹窗。

`bare` 加载层和 `:opening-motion="false"` 不播放弹窗动效。H5 遵循系统“减少动态效果”，不等待导航动画和弹窗动画。

- `tests/page-motion.test.mjs` 验证全部已登记业务路由、导航方向、重置/鉴权排除及 App 参数保持。
