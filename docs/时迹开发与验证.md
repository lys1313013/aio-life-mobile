# 移动端时迹开发与验证

当前跨端需求以[今日时迹卡片设计](../../docs/今日时迹卡片设计.md)为准。下文日期小节保留历史测试范围与失败结果，不代表当前提交重新通过。命令从移动端仓库根目录执行。

时迹时间轴按页面滚动容器的实际可用高度铺满首屏：扣除顶部细节间距与日期表头后，其余高度按 1440 分钟等比分配，不再使用固定窗口高度扣减。导航、底栏和安全区由页面容器负责；手机和平板的统计区域保留在时间轴下方，向下滚动查看。窗口变化和返回页面时重新测量，不根据滚动后的时间轴位置计算高度。

时迹的接口与界面起止分钟都采用闭区间，例如 23:10–23:33 为 24 分钟。当前三个入口默认共用精简编辑器：日期为原生日期 picker；起止时间使用 `TimeEndPicker`，小时使用 `picker-view`，分钟使用连续的 `scroll-view` 并跨小时联动，选择范围受相邻记录边界约束，时长自动计算。下文历史记录中的小时 / 分钟时长输入与快捷调整不代表当前精简布局。首页待记录时长为当前分钟减去最新记录的结束分钟再减一，没有记录或正在浏览历史日期时仅显示加号。

**待对齐：** 上述 `TimeEndPicker` 为自定义选择层，与 `AGENTS.md` 中起止时间使用原生 picker 的要求仍有差异；记录当前实现不代表规范已满足。本轮未修改时间交互，后续需对照 Web 并完成跨端手势、边界与真机验证后处理。

首页时迹卡片支持左滑后一天、右滑前一天，最晚为今天；H5 兼容鼠标拖动与触控板横滑。历史日期单独保存，周期刷新读取正在浏览的日期；首页新增使用卡片当前显示的日期，推荐时段及保存沿用该日期；未切换日期时默认今天，编辑历史记录按记录自身日期加载。相关逻辑位于 `src/pages/home/services/time-card-swipe.ts`，模拟回归为 `tests/home-time-swipe.test.mjs`。

首页时迹圆环在微信端使用 `TimeDonut.uvue` 的普通 `image` 分支，`time-donut-image.ts` 生成 SVG，沿用图标的 Base64 图片方式。屏幕 Canvas 在开发者工具的 `scroll-view` 内可能停留在旧位置，覆盖后续卡片；不能只靠 `z-index`、裁切或滚动后重绘修补。图片与总时长、标签一起滚动和缩放，直接显示完整环；H5 / App 保留原 Canvas 分支。两种实现共用分类比例、旋转角和引导线算法。

目标卡片的 `GoalProgressRing.uvue` 在微信端同样使用矢量图片，避免进度弧线残留在其他卡片上；保留 56px 几何、圆头端点、百分比和语义进度条。

专项回归：`node --test tests/time-donut-modal.test.mjs tests/dashboard.test.mjs`、`npm exec playwright test tests/e2e/home-time-donut.spec.js`；`node tests/wechat-ui/time-donut.mjs` 在忽略的隔离工程中编译微信图片分支，覆盖三类视口、深浅主题、像素比例、滚动、重排、弹窗和图片失败重试。隔离工程、截图在 `artifacts/wechat-time-donut/`，它不等同于微信模拟器或真机验证；微信仍需构建后实际检查滚动、离页返回及弹窗遮挡。

复用新增按钮时放在页面根容器内、滚动容器外：

```vue
<FloatingActionButton label="新增时迹" :disabled="loading" @click="handleAdd" />
```

组件支持 `label`、`disabled`、`loading`、`bottom`、`right`；当前按钮在宽度不超过 1024px 时为 48px，更宽时为 56px。默认偏移读取 `spacing.page + spacing.inline`，不要在业务页面复制数值。微信端固定定位，在 tab 页额外避让 `tabBarInset()` 返回的页面内底栏高度，并叠加底部安全区；其他端相对已扣除原生 tabBar／安全区的页面定位。
